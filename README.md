# Hebrew_anki

Anki-колода «Иврит::Частотный словарь» для AnkiDroid: 1150 самых частотных слов иврита
(по частотному словарю субтитров [juandpinto/frequency-dictionary](https://github.com/juandpinto/frequency-dictionary)),
с огласовками, ударением, переводом на русский, формами глаголов, управлением и местоименными парадигмами.

## Сборка

```bash
pip install genanki
python3 make_deck.py            # полная колода → hebrew_frequency.apkg
python3 make_deck.py 570 821    # патч только с этими записями → hebrew_patch_570_821.apkg
```

Патч импортируется в Anki поверх колоды («Пакет колоды Anki (.apkg)») и обновляет
записи по GUID — прогресс повторений сохраняется.

## Нельзя менять (иначе потеря прогресса)

- `MODEL_ID = 1874423002`, `DECK_ID = 2059400111`, `GUID_SEED = "he-freq-v2"`
- `DECK_NAME = "Иврит::Частотный словарь"`
- порядок полей: Hebrew, Niqqud, Russian, Note, Forms, Rank
- при изменении поля Hebrew у записи — добавить прежнее значение в `GUID_KEY`

## Правила оформления

- у глаголов, форм глаголов и глаголов в заметках всегда указывается инфинитив
- спорные огласовки, значения и формы сверяются: Академия языка иврит, Викисловарь, Pealim
